# 英语国际音标学习网站

一个帮助英语学习者掌握48个国际音标(IPA)的互动学习平台。

## 功能特点

- **完整的48个国际音标**：包含20个元音和28个辅音
- **英美发音对比**：每个音标都支持英式和美式发音
- **一键发音**：使用 Web Speech API 播放英音和美音示例词
- **发音技巧**：每个音标都配有详细的中文发音指导
- **学习进度追踪**：自动记录已学习的音标
- **英美差异对照表**：常见单词的英美发音差异
- **常见错误提醒**：中国学习者常犯的发音错误

## 技术栈

- HTML5
- CSS3 (自定义样式，无框架依赖)
- JavaScript (原生 ES6+)
- Web Speech API (发音功能)
- LocalStorage (进度存储)

## 部署

该项目可直接部署到 GitHub Pages：

1. Fork 或复制此仓库
2. 进入仓库 Settings → Pages
3. 选择 Source: Deploy from a branch, Branch: main
4. 等待部署完成
5. 访问 `https://[username].github.io/[repo-name]/`

## 本地运行

直接在浏览器中打开 `index.html` 文件即可。

## 浏览器兼容性

- Chrome 80+
- Firefox 75+
- Safari 14+
- Edge 80+

注：Web Speech API 在部分移动浏览器可能不支持。浏览器语音合成不能直接读取 IPA 字符，因此音标详情页的英音/美音按钮会以较慢速度播放一个包含目标音的示例词；单词示例按钮则播放对应单词。

## 音标分类

### 元音 (20个)

**短元音**: /ɪ/, /e/, /æ/, /ʌ/, /ə/, /ɒ/, /ʊ/

**长元音**: /iː/, /ɑː/, /ɔː/, /uː/, /ɜː/

**双元音**: /eɪ/, /aɪ/, /ɔɪ/, /aʊ/, /əʊ/, /ɪə/, /eə/, /ʊə/

### 辅音 (28个)

**爆破音**: /p/, /b/, /t/, /d/, /k/, /ɡ/

**摩擦音**: /f/, /v/, /θ/, /ð/, /s/, /z/, /ʃ/, /ʒ/, /h/, /r/

**破擦音**: /tʃ/, /dʒ/, /tr/, /dr/, /ts/, /dz/

**鼻音**: /m/, /n/, /ŋ/

**近音**: /w/, /j/

**边音**: /l/
